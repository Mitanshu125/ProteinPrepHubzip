# ProteinPrepHub 🥗💪

A full-stack nutrition platform for high-protein meal planning, tracking, and recipes.

## 🌐 Live Demo
https://proteinprephub.vercel.app

## Features
- 17 High-protein recipes with nutrition facts
- Daily Protein Goal Tracker
- Weekly Meal Planner
- BMI Calculator
- Search, Filter & Sort recipes
- Recipe sharing via email

## Tech Stack
- **Frontend:** React, Vite, CSS
- **Backend:** Node.js, Express
- **Deployed on:** Vercel
